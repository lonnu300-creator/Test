# فرنوا — نسخه رایگان ۱.۰.۰

فرنوا یک برنامه رایگان برای مدیریت فاکتورهای فروش و خرید، ثبت هزینه‌ها، پیگیری دریافتی و مانده حساب است. همه قابلیت‌ها در همین نسخه در دسترس هستند؛ هیچ پلن لایت یا پرمیوم، تبلیغ یا پرداخت درون‌برنامه‌ای وجود ندارد.

## امکانات
- ثبت و ویرایش فاکتور فروش و خرید
- ثبت کالا و خدمت، تعداد، قیمت، تخفیف و مالیات
- مبلغ پرداخت‌شده، مانده قابل تسویه و تاریخ سررسید
- وضعیت تسویه کامل، پرداخت بخشی و تسویه‌نشده
- بستن و بازگشایی فاکتور بدون حذف مانده
- ثبت هزینه‌ها و داشبورد مالی
- نمودار تعاملی فروش، خرید، هزینه و مانده بر اساس ماه شمسی
- ورود و نمایش تاریخ شمسی
- چهار قالب فاکتور: رسمی کلاسیک، مدرن، مینیمال و لوکس
- انتخاب فونت: وزیرمتن، آبار، لاله‌زار و انجمن
- پیش‌نمایش زنده، درج لوگو و مهر کسب‌وکار
- اشتراک‌گذاری PDF، DOCX، PNG و JPG
- اندازه‌های A4، A5 و رسید ۸۰ میلی‌متری
- بکاپ و بازیابی فایل‌محور، بدون حساب و سرور
- رابط موبایل‌محور، دکمه‌های بزرگ، انیمیشن و صدای اختیاری

## مشخصات برنامه
- نام نمایشی: فرنوا
- شناسه برنامه: `ir.farnava.app`
- نسخه: `1.0.0`
- حداقل SDK: 23
- Target SDK: 36
- مدل دسترسی: کاملاً رایگان

**شناسه برنامه را پیش از اولین انتشار در پیشخان بازار بررسی کنید.** پس از انتشار، تغییر شناسه باعث می‌شود برنامه محصولی جدا محسوب شود و به‌روزرسانی نصب قبلی ممکن نباشد.

## ساخت APK آزمایشی
1. محتویات ZIP را در ریشه مخزن GitHub قرار دهید.
2. از Actions، گزینه `Build Farnava Debug APK` را اجرا کنید.
3. فایل `farnava-debug-apk` را از Artifacts دانلود و روی گوشی آزمایش کنید.

APK دیباگ فقط برای آزمایش است و برای انتشار عمومی استفاده نشود.

## ساخت APK امضاشده برای بازار
برای انتشار عمومی باید یک کلید امضای ثابت داشته باشید. آن را یک‌بار بسازید و برای تمام نسخه‌های بعدی نگه دارید.

در PowerShell ویندوز با نصب بودن JDK اجرا کنید:

```powershell
keytool -genkeypair -v -keystore farnava-release.jks -alias farnava -keyalg RSA -keysize 4096 -validity 10000
```

فایل `farnava-release.jks` و رمزهای آن را در محل امن نگهداری کنید. کلید را داخل GitHub یا ZIP پروژه قرار ندهید.

برای ساخت مقدار Base64 در PowerShell:

```powershell
$bytes = [System.IO.File]::ReadAllBytes("$PWD\farnava-release.jks")
$base64 = [Convert]::ToBase64String($bytes)
Set-Clipboard $base64
```

در GitHub بروید به:
`Settings → Secrets and variables → Actions → New repository secret`

این چهار Secret را بسازید:
- `FARNAVA_KEYSTORE_BASE64` — مقدار Base64 کلید
- `FARNAVA_KEYSTORE_PASSWORD` — رمز keystore
- `FARNAVA_KEY_ALIAS` — در فرمان بالا مقدار `farnava`
- `FARNAVA_KEY_PASSWORD` — رمز کلید

سپس از Actions، گزینه `Build Farnava Market Release APK` را اجرا کنید. فایل خروجی `farnava-market-release-v1.0.0` یک APK امضاشده است.

از دست‌دادن کلید امضا می‌تواند انتشار به‌روزرسانی برای نصب‌های قبلی را مختل کند؛ چند نسخه پشتیبان امن از کلید نگه دارید.

## مجوز فونت‌ها
- Vazirmatn و Lalezar با مجوز SIL Open Font License دریافت می‌شوند؛ فایل مجوز آن‌ها در `www/font-licenses` قرار می‌گیرد.
- فایل‌های Abar و Anjoman ارائه‌شده توسط صاحب پروژه هستند. پیش از انتشار عمومی، مجوز توزیع و جاسازی آن‌ها را بررسی کنید. اگر مجوز توزیع ندارید، آن‌ها را از نسخه بازار حذف کنید.

## حریم خصوصی
سیاست حریم خصوصی در `PRIVACY_POLICY_FA.md` و `www/privacy.html` قرار دارد. اطلاعات فاکتورها و کسب‌وکار در حافظه محلی دستگاه ذخیره می‌شوند. برنامه حساب کاربری، تبلیغات، سرویس ابری یا ارسال خودکار اطلاعات به سرور فرنوا ندارد. اشتراک‌گذاری فایل فقط پس از اقدام کاربر و با برنامه‌ای که خودش انتخاب می‌کند انجام می‌شود.

فایل `www/privacy.html` را روی یک نشانی عمومی و پایدار میزبانی کنید و نشانی آن را در پیشخان بازار ثبت کنید.
